# 📚 A web application designed for reviewing, verifying, and filtering Thai examination datasets.


**🌟 Key Features**

Blind Testing Mode: Hides correct answers and explanations by default so reviewers can test the questions firsthand.


**🏷️ Review Decisions:**

Approved: The question is complete and ready for use.

Need Edit: Contains minor issues requiring adjustment (e.g., typos, ambiguous explanations).

Reject: Contains severe errors or is unusable.

Discuss: Requires team consultation before making a final decision.

Quick Issue Tags: Rapidly tag specific problems such as incorrect answers, duplicate options, or imprecise royal vocabulary.



**💾 Auto-save & Draft Storage:**
Automatically saves review progress and drafts to the browser's LocalStorage to prevent data loss if a tab is accidentally closed.



**📊 Diagnostics Dashboard:**

Overview statistics of passed and failed questions.

Breakdown table by difficulty level (Easy / Medium / Hard).

Breakdown table by subcategory.



**📥 CSV Export (Excel Ready):**

Export all review results along with timestamps.

Export only flagged questions requiring corrective action.

## ⌨️ Keyboard Shortcuts

| key | Action |
| :--- | :--- |
| **`←` / `→`** | Navigate questions (Previous / Next) |
| **`Spacebar`** |Toggle answer and explanation visibility|
| **`1`** |  Approved |
| **`2`** | Need Edit |
| **`3`** | Reject |
| **`4`** |  Discuss |
| **`Ctrl` + `Enter`** | Save result and jump to the next unreviewed question |
